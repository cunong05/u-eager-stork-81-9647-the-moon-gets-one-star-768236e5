## The entry

`main.py` writes one one-star review of the Moon to `/output/entry.txt` — a single line of at most 120 characters.

> 1 star. Only works nights, vanishes for a week every month, and still floods my beach twice a day. Would not recommend.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies, no network, no secrets. The program only writes the entry text.
